**Title**:
[PR Feedback] Mobile Breakpoint and First-Render Flash

**Description**:
Based on consolidated PR review, address the following in **Mobile Breakpoint and First-Render Flash**:

- **`useMediaQuery` + missing CSS defense-in-depth causes layout flash on mobile**: `src/hooks/useMediaQuery.ts:4` always initializes `isMobile` to `false`. On a mobile device the first render shows the full desktop sidebar column, then `useEffect` fires and React re-renders to show the Drawer. The architecture explicitly specified `@media (max-width: 768px) { .shell-layout__sidebar-col { display: none; } }` and `@media (min-width: 769px) { .shell-layout__mobile-menu-toggle { display: none; } }` in `src/components/ShellLayout.css` as CSS fallbacks to prevent this flash — neither rule was implemented.
- **CSS/JS breakpoint divergence creates broken hybrid state**: CSS media queries in `src/components/Topbar.css:112` and `src/components/Statusbar.css:125` hardcode `@media (max-width: 768px)`, but `ShellLayout` accepts a configurable `mobileBreakpoint` prop (`src/components/ShellLayout.tsx:19`). If a consumer passes a non-default value, CSS fires at 768px while the JS sidebar switches at the custom value — producing a broken hybrid layout in between.
