Phase 9: Layout Canvases — Calendar & MiniCalendar

**Description**:
Build the `Calendar` component for the Events screen with month/week/day/agenda views, event bars per calendar identity, and full keyboard navigation, alongside the `MiniCalendar` companion for date-picker sidebars.

## Requirements
- FR-CA-1: 7-column month grid from `dateUtils.getMonthGrid`; out-of-month cells muted (`--canvas-fg-4`); today's cell has amber Chip on date number with `aria-current='date'`; cell overflow shows '+N more'
- FR-CA-2: Event bars rendered as left-accent bars inside cells, colored by `calendarId` registry; `renderEvent` escape hatch replaces default bar; `onSelectEvent(id)` callback
- FR-CA-3: Four views (month/week/day/agenda); view switcher reuses `SegmentedControl`; prev/next/today navigation reuses `Button`; view and navigation are fully controlled via `onChangeView` and `onNavigate`
- FR-CA-4: All date math via `src/utils/dateUtils.ts`; `weekStartsOn` (0=Sunday, 1=Monday) respected across all views; no third-party date library
- FR-CA-5: Arrow keys move day focus; Enter/Space selects focused date or event; PgUp/PgDn navigate months; Home/End jump to week start/end; `role='grid'` with `role='row'` and `role='gridcell'`
- FR-CA-6: `MiniCalendar` renders compact month grid with `markers` (Date[]) dots, today highlight, selected-day highlight, and `onSelect(date)` callback
- FR-CC-1/2/4/5/6/7: `forwardRef`, token-only CSS, exported from `src/index.ts`, test page, Playwright spec, docs showcase

## Design Guidance
Implements the 'Phase 4a — Calendar + MiniCalendar' section of the architecture design, including ADR-4 (shared dateUtils instead of a date library) and SegmentedControl/Button reuse for view chrome.
