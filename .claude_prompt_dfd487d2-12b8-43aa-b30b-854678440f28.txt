**Title**:
Phase 1: usePanZoom hook extraction

**Description**:
Extract the inline pan/zoom logic from `GraphCanvas.tsx` into a standalone `src/hooks/usePanZoom.ts` hook, then refactor `GraphCanvas` to consume it. This is a prerequisite for `MapCanvas` and must land with zero visual regression on existing GraphCanvas Playwright snapshots.

## Requirements
- FR-PRE-2: Create `src/hooks/usePanZoom.ts` exposing `{ transform, viewport, bind, zoomTo, panTo, reset }`
- Hook returns a CSS `matrix()` string usable by both SVG `<g transform>` attributes and CSS `transform` properties
- `bind` spread provides `onPointerDown`, `onWheel`, `onKeyDown`, `tabIndex`, and `role`
- `+`/`-` keyboard keys zoom by a step; arrow keys pan
- Zoom clamps to configurable `minZoom`/`maxZoom`; GraphCanvas uses 0.4–2.5
- Optional `bounds` clamps panning to content extents
- `onViewportChange` callback fires with `{ x, y, zoom }` on any viewport change
- `prefers-reduced-motion` skips inertial easing
- Refactor `GraphCanvas.tsx` to call `usePanZoom({ minZoom: 0.4, maxZoom: 2.5 })` and apply returned `transform` to its `<g>` element; no inline pan/zoom logic may remain
- Export `usePanZoom`, `UsePanZoomOptions`, and `UsePanZoomReturn` types from `src/index.ts`
