**Title**:
Phase 7: Cards & Lists — AssetCard & AssetGrid

**Description**:
Build `AssetCard` with a discriminated-union thumbnail system and its companion `AssetGrid` layout wrapper, used on Documents and Music screens for consistent grid-view presentation of documents and media assets.

## Requirements
- FR-AC-1: `AssetThumb` discriminated union with three modes — `doc` (pure CSS page-fold + extension tab, no network request), `cover` (gradient + Icon glyph, optional image overlay), `image` (real image, `object-fit: cover`); `image` and `cover` modes fall back to glyph on load error with no layout shift
- FR-AC-2: Two-line-clamped title, optional subtitle in secondary mono, optional `meta` node, and optional corner `badge` string rendered in amber tint
- FR-AC-3: `selected=true` shows amber border ring and sets `aria-selected='true'`
- FR-AC-4: `AssetGrid` wraps AssetCard children with `columns` and `gap` controlled via `--asset-columns` and `--asset-gap` CSS custom properties, matching the `StatGrid`/`QuickAccessGrid` pattern
- FR-CC-1/2/4/5/6/7: `forwardRef`, token-only CSS, exported from `src/index.ts`, test page, Playwright spec, docs showcase

## Design Guidance
Implements the 'Phase 3b — AssetCard + AssetGrid' section of the architecture design, including the three discriminated thumbnail rendering paths and CSS grid wrapper pattern.

## Acceptance Criteria
- [ ] `thumb: { kind: 'doc', ext: 'pdf' }` renders a page-fold thumbnail with 'pdf' tab using only CSS (no network request)
- [ ] `thumb: { kind: 'cover', gradient, glyph }` renders gradient background with the specified icon
- [ ] `thumb: { kind: 'image', src }` with valid URL renders image at full cover; broken `src` falls back to glyph with no layout shift
- [ ] `selected=true` shows amber border ring and `aria-selected='true'`
- [ ] `badge='cited'` renders a corner chip with amber tint text
- [ ] Title clamps to two lines on overflow
- [ ] `AssetGrid` with `columns={3}` renders a 3-column grid via CSS custom properties
- [ ] `AssetCard`, `AssetGrid`, `AssetCardProps`, `AssetGridProps`, and `AssetThumb` types exported from `src/index.ts`
- [ ] Playwright spec snapshots cover all three thumb modes, selected, badge, and error fallback states in both light and dark canvas
