**Title**:
Phase 3: Versioning Suite — LineageRail

**Description**:
Build the `LineageRail` component that renders a directed chain of pipeline stages as node pills connected by arrow glyphs, used on Chunk inspector and Messages screens to display data provenance.

## Requirements
- FR-LR-1: Render `LineageNode[]` as pills separated by `→` arrow glyphs in `--canvas-fg-4`; each node shows an optional leading icon and a monospace label; the `head` node gets amber tint background (`--accent-primary-bg-alpha-sm`) and amber border (`--accent-primary-border-alpha-sm`)
- FR-LR-2: When `wrap=false` (default), rail scrolls horizontally without truncating any node; when `wrap=true`, nodes wrap to new lines with arrows maintained
- FR-LR-3: Nodes without `onClick` are non-interactive text spans; nodes with `onClick` are button elements; hover lifts border to `--canvas-border-strong`; focus applies `--focus-ring`
- FR-LR-4: `role='list'` on container; arrow separators are `aria-hidden`; head node has `aria-current`; container has `aria-label` summarizing the chain
- Single-node rail shows no arrow separator; empty `nodes` array renders nothing
- FR-CC-1/2/4/5/6/7: `forwardRef`, token-only CSS, exported from `src/index.ts`, test page, Playwright spec, docs showcase

## Design Guidance
Implements the 'Phase 2a — LineageRail' section of the architecture design, including the compound component pattern for internal nodes and Chip reuse for node pill styling.

## Acceptance Criteria
- [ ] Head node renders with amber tint background and amber border; non-head nodes render in neutral surface style
- [ ] With 10+ nodes and `wrap=false`, the rail scrolls horizontally and no node is truncated
- [ ] With `wrap=true`, nodes wrap to new lines with arrows correctly positioned between them
- [ ] Nodes without `onClick` are non-interactive spans; nodes with `onClick` are keyboard-activatable buttons (Enter/Space fires handler)
