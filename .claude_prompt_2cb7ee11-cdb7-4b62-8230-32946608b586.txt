**Title**:
Phase 11: Layout Canvases — MapCanvas

**Description**:
Build the `MapCanvas` component for the Location screen — a pannable, zoomable geographic canvas with pin, track, and heatmap rendering modes — built on the `usePanZoom` hook from Phase 1.

## Requirements
- FR-MC-1: Three rendering modes via `mode` prop: `pins` (data-driven `<button>` markers with mono label chips), `track` (dashed cyan SVG polyline connecting ordered points), `heatmap` (density overlay reusing the existing Heatmap color scale — no independent color ramp)
- FR-MC-2: When `tileUrl` string template is provided, fetch and render raster tiles in a CSS grid at appropriate zoom; when absent, render abstract grid fallback matching GraphCanvas treatment; no tile vendor hardcoded in source
- FR-MC-3: All pan/zoom via `usePanZoom` hook; GPU-friendly CSS `matrix()` transform on a single transformed layer; `bounds` fits initial viewport to all content; viewport controllable with `onViewportChange`
- FR-MC-4: Pins are `<button>` elements with `aria-label` of place + timestamp; active pin shows design-system pulse animation (suppressed under `prefers-reduced-motion`); selected pin (`selectedPinId` + `onSelectPin`) shows popover with `detail` content; Escape closes popover
- FR-MC-5: Overlay chrome (legend, scale bar when `scaleBar=true`, mode switch) rendered outside the transformed layer using shell-surface blur treatment; arrow keys pan, `+`/`-` zoom within clamped range
- FR-MC-6: `role='application'` on canvas container; Mercator projection (`latLng ↔ pixel`) implemented as internal utility (not exported); tile URL template follows `{x}/{y}/{z}` de facto standard
- FR-CC-1/2/4/5/6/7: `forwardRef`, token-only CSS, exported from `src/index.ts`, test page, Playwright spec, docs showcase

## Design Guidance
Implements the 'Phase 4c — MapCanvas' section of the architecture design, including ADR-5 (internal Mercator projection) and ADR-7 (CSS `matrix()` from usePanZoom).

## Acceptance Criteria
- [ ] Without `tileUrl`, the full canvas area renders an abstract grid with no blank regions
- [ ] With `tileUrl`, tiles are fetched and rendered; no map vendor URL is hardcoded in the component source
- [ ] `mode='pins'` renders each pin as a `<button>` with `aria-label` and a monospace label chip
- [ ] Active pin displays the design-system pulse animation; animation is suppressed under `prefers-reduced-motion`
- [ ] Selecting a pin shows its `detail` popover; Escape closes it; `onSelectPin` fires
- [ ] `mode='track'` renders a dashed cyan polyline connecting track points
- [ ] `mode='heatmap'` uses the existing Heatmap color scale with no independent color ramp defined in MapCanvas
- [ ] `bounds` prop fits the initial viewport to show all content within those bounds
- [ ] Arrow keys pan; `+`/`-` zoom within clamped range; `onViewportChange` fires with `{ center, zoom }` on every change
- [ ] Scale bar overlay appears when `scaleBar=true`; overlay chrome is outside the transformed layer
- [ ] `MapCanvas` and all public types exported from `src/index.ts`
- [ ] Playwright spec snapshots cover grid-only, pins, track, heatmap, and active-pin states in both light and dark canvas
