Based on consolidated PR review, address the following in **Edge Hover State**:

- **Stale `hoveredEdgeId` when non-structural edge hides while pointer is on it**: In `src/components/GraphCanvas.tsx:1878`, the `touchesFocus` visibility check for non-structural edges does not include `edge.id === hoveredEdgeId`. When a user moves the pointer from a node onto an adjacent non-structural edge, React 18 batching clears `hoveredNodeId` and sets `hoveredEdgeId` in one render — `touchesFocus` evaluates false, the edge unmounts (no `pointerleave` fires), and `hoveredEdgeId` is permanently stale. The existing cleanup effect (lines 558-566) only checks edges removed from the `edges` prop, not edges hidden by `isStructuralEdge`. Fix: add `edge.id === hoveredEdgeId` to `touchesFocus`.
