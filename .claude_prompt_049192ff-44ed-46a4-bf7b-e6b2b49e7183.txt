**Title**:
Phase 2: Avatar primitive

**Description**:
Build the `Avatar` component — the foundational people-identifier primitive used across Rail, Messages, and People screens. Renders a person's photo or deterministic initials gradient with optional presence dot.

## Requirements
- FR-AV-1: Render up to two initials from `name` (first letter of each word, uppercased) in JetBrains Mono on a 135° gradient from `--accent-primary` to `--accent-primary-deep`; gradient hue is deterministic per name (same name → same color every time)
- FR-AV-2: When `src` is provided, render image with `object-fit: cover`; on load error, revert to initials with no layout shift
- FR-AV-3: Four sizes — `xs` (20 px), `sm` (28 px), `md` (36 px, default), `lg` (64 px); two shapes — `circle` (default) and `rounded` (`--radius-md`)
- FR-AV-4: When `status` (`StatusColor`) is provided, render a presence dot at bottom-right on a `--canvas-card`-colored ring; dot carries its own `aria-label`
- FR-AV-5: Standalone Avatar has `role='img'` and `aria-label={name}`; decorative Avatar inside an already-labelled row is `aria-hidden='true'`
- FR-CC-1/2/4/5/6/7: `forwardRef`, token-only CSS, exported from `src/index.ts`, test page, Playwright spec, docs showcase

## Design Guidance
Implements the 'Phase 1 — Avatar' section of the architecture design.
